# Shared Evaluation

Thư mục này dành cho tài liệu và hạ tầng evaluation dùng chung trong tương lai. Các team có thể dùng chung evaluation infrastructure khi phù hợp.

- Team 1: retrieval metrics, ví dụ Recall@K và MRR.
- Team 2: RAG metrics, Citation Accuracy, Answer Quality và Hallucination/Grounding.
