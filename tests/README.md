# Shared Tests

Test dùng chung giữa các team. Test riêng của từng team nằm cạnh code của team đó (ví dụ `team2_rag/tests/`).

| Test | Kiểm tra |
|---|---|
| `test_preprocess_legal_data.py` | Script `scripts/preprocess_legal_data.py` |
| `test_team2_mock.py` | Mock của Team 2 theo schema contract |
